Forensics C: one-sheet notes (print both sides, 8.5 x 11, no affixed labels)

Score

  • 3.b solids 20, 3.c polymers 20, 3.d chromatography 15, 3.e scene 15, 3.f analysis 30
  • Tie: best analysis wins. Cleanup 10%, prohibited gear up to 10%

Flame

  • Li crimson, Na yellow, K lilac, Ca brick red, boron green

Solids tests

  • HCl fizz: Na2CO3, NaHCO3, CaCO3
  • Acetate + HCl: vinegar smell
  • NaOH + warm: NH3 smell = NH4Cl; white cloud = MgSO4
  • Iodine blue-black = starch
  • Benedict's + heat: glucose orange, sucrose stays blue
  • Insoluble: CaCO3, CaSO4 (slightly), starch
  • pH: Na2CO3 ~11, NaHCO3 and acetate ~8-9, boric acid and NH4Cl ~5

Plastics (density g/cm3)

  • PP 0.90, LDPE 0.92, HDPE 0.95 float in water
  • PS 1.05, PMMA 1.18, PC 1.20, PVC 1.3-1.4, PETE 1.38 sink
  • #1 PETE, #2 HDPE, #3 PVC, #4 LDPE, #5 PP, #6 PS
  • PVC: green edge, acrid. PS: sooty, sweet. PE/PP: candle

Fibers

  • Cotton, linen: paper smell, gray ash (plant)
  • Wool, silk: burning hair, crushable ash (animal)
  • Nylon: melts, celery, hard bead. Polyester: sooty, sweet, hard bead. Spandex: melts, stretches
  • Cotton twisted ribbon, linen nodes, wool scales

Hair

  • Cuticle (scales), cortex (pigment), medulla (center), root
  • Medullary index = medulla / width: human < 1/3, animal > 1/2
  • Scales: coronal, spinous, imbricate. Tag = nuclear DNA

Chromatography

  • Rf = spot distance / solvent distance (0 to 1)
  • Pencil line, solvent below it, mark the front
  • TLC: silica (polar); less polar runs farther
  • Mass spec: M+ = highest m/z, base peak = tallest. 15 CH3, 18 H2O, 28 CO, 29 C2H5, 43, 77 phenyl

Fingerprints

  • Arch 0 deltas (plain, tented), loop 1 (radial = thumb side, ulnar = pinky side), whorl 2 (plain, central pocket, accidental, double loop)
  • Loops 60-65%, whorls 30-35%, arches 5%
  • Bifurcation, trifurcation, island, enclosure, spur, delta
  • Paper: ninhydrin (purple, amino acids). Plastic/metal: super glue. Iodine: brown, fades. Dust: contrast powder

DNA and blood

  • PCR: denature 95C, anneal 50-60C, extend 72C. Copies = start x 2^n
  • Every locus must match; one mismatch excludes
  • Clumps with anti-A only = A, anti-B only = B, both = AB, neither = O
  • No nucleus = mammal. Nucleus = bird (small oval), reptile/amphibian (large oval)

Glass, tracks, bullets

  • n = c / v. Chip vanishes when oil n = glass n
  • Radial first, concentric later. The crack that stops is later. 3R rule
  • Height = foot / 0.15. Tire: tread, track width, wheelbase
  • Bullets: lands/grooves/twist = class; striations = individual

Spatter and insects

  • sin(angle) = width / length
  • Height = distance x tan(angle)
  • Low > 4 mm, medium 1-4 mm, high < 1 mm
  • Oldest insect stage + temperature = minimum time since death

Analysis (30%)

  • 1 Name the culprit. 2 Each test and who it points to. 3 For EACH other suspect, the evidence that clears them. 4 Weak or class evidence. Use numbers
  • Class narrows, individual names
